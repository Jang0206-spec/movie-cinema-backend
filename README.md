# 🎬 Movie Cinema

> 상태: 🚀 Phase 1
> 
> 본 프로젝트는 학부 과정에서 개발한 MySQL 연동 영화 예매 서비스를 기반으로 합니다. 현재 저장소는 1차 인프라 데이터 모델의 백업 본이며, 데이터 엔지니어링 관점에서 레거시 구조의 안티패턴을 식별하고 이를 안정적이고 확장 가능한 데이터 파이프라인 아키텍처로 고도화하는 전체 리팩토링 과정을 기록합니다.

---

## 🗺️ Data Architecture Roadmap

- [x] Phase 1. 레거시 데이터 모델 분석 및 데이터 백업
  - Spring Data JPA 인프라 마이그레이션을 통한 객체 지향 엔티티 매핑 및 HikariCP 커넥션 풀 최적화를 통한 디스크 I/O 성능 향상
- [ ] Phase 3. 동시성 제어 및 초고속 인메모리 데이터 락 설계
  - 콤마 분리 문자열 기반 좌석 데이터 적재 방식의 제1정규형 위반 데이터 모델 식별 및 아카이빙 완료
  - 원시 JDBC 기반 커넥션 관리 루틴 분석 및 수동 데이터 트림 처리의 예외 로직 분석 완료
- [ ] Phase 2. 데이터 모델링 정규화 및 데이터 접근 계층 고도화
  - 테이블 정규화 수행: movie_reservation 테이블의 복합 속성을 쪼개어 1:N 식별 관계의 새로운 예매-좌석 매핑 구조 테이블 설계 및 반영
  - 가상 부하 테스트 툴을 활용한 선착순 대용량 예매 트래픽 환경 구성
  - RDBMS 격리 수준 검증 및 Redis 인메모리 데이터 솔루션을 활용한 분산 락 기법 설계로 다중 트랜잭션 충돌 시 데이터 정합성 보장 구조 확립
- [ ] Phase 4. 쿼리 튜닝 및 대용량 데이터 파이프라인 확장
  - 수만 건 이상의 가상 데이터 적재 후 MySQL EXPLAIN 분석을 통한 병목 포인트 추출
  - 탐색 속도 향상을 위한 복합 인덱스 최적화 및 LIMIT 기반 오프셋 페이징의 한계를 극복하는 No-Offset 페이징 기법 도입
  - 비동기 처리 가속화를 위한 Apache Kafka 메시지 큐 연동 및 데이터 가드레일 수립

## 💾 데이터베이스 설계 요약

시스템 내 데이터 무결성과 엔티티 간 유기적 결합을 위해 총 4개의 테이블을 물리 모델링하여 구성했습니다.

* member: 사용자 ID를 PK로 사용하며, 암호화된 비밀번호, 연락처 및 시스템 접근 권한 스키마를 포함하여 관리자와 일반 사용자의 보안 권한을 분리합니다.
* movie: 고유 식별자를 기반으로 영화 제목, 감독, 장르, 티켓 단가, 러닝타임 및 포스터 이미지 참조 경로를 저장합니다.
* movie_reservation: 예매 트랜잭션의 중심 테이블입니다. member 및 movie 테이블과 연관 관계를 가지며, 상영 스케줄, 인원 수, 원시 문자열 형태의 좌석 목록 및 최종 결제 상태 이력을 기록합니다.
* review: member 및 movie에 대한 외래키 성격의 데이터를 가지며, 유저의 평점 스키마, 피드백 텍스트 데이터 및 데이터 적 적재 시점을 기록합니다.

## 🏗️ 코드 및 시스템 설계 요약

데이터베이스와 사용자 화면 사이의 안정적인 데이터 파이프라인 구축을 위해 표준 MVC 아키텍처를 채택했습니다.

* Controller: 사용자의 HTTP 요청을 수신하고, 세션 유효성 검증 및 데이터 무결성 체크를 수행한 후 적절한 Model 로직을 호출합니다.
* DAO / DTO 패턴: 
  * DAO: 원시 JDBC 쿼리 실행 및 커넥션 관리를 전담하여 비즈니스 로직과 DB 접근 로직을 완벽히 분리했습니다.
  * DTO: 쿼리 결과 셋을 객체지향적인 Java 데이터 구조로 매핑하여 계층 간 데이터 전송의 안전성을 확보했습니다.
* 보안 및 세션 제어: 사용자 비밀번호 수집 시 SHA-256 단방향 해시 알고리즘을 적용해 평문 데이터 유출을 차단했으며, HttpSession 객체를 기반으로 비인가 사용자의 관리자 데이터 접근을 제어합니다.

## 🛠️ 기술적 챌린지 및 데이터 트러블슈팅

### 1. 웹 컨텍스트 동적 절대 경로 표준화를 통한 404 에러 방어
* 문제 상황: 계층 깊이가 상이한 멀티 디렉토리 구조 내의 JSP 파일들이 단일 공통 헤더 템플릿을 인클루드하여 처리할 때 상대 경로 깨짐 현상 및 데이터 로드 실패 현상 발생.
* 해결 방법: 정적 경로 선언 방식을 폐기하고, 내장 객체 메서드인 request.getContextPath 아키텍처를 적용하여 가상 루트 경로를 실시간으로 동적 추출하는 절대 경로 시스템으로 변환하여 완벽한 인프라 유연성 확보.

### 2. 문자열 공백 데이터 트림 처리를 통한 권한 정합성 검증
* 문제 상황: 데이터베이스 단에서 수동으로 회원 권한 플래그 데이터를 admin으로 업그레이드했으나, 애플리케이션 메모리 런타임 상에서 데이터 검증 실패로 인해 권한 누수 오류 지속 발생.
* 해결 방법: 실행 흐름 디버깅 및 콘솔 추적을 진행한 결과 데이터베이스 적재/추출 과정 중 문자열 후미에 보이지 않는 공백 레코드가 유입되어 equals 조건 정합성 매칭이 깨지는 현상 포착. Controller 비즈니스 로직 진입점에 데이터 무결성 보장을 위한 trim 정제 파이프라인을 추가하여 권한 무결성 로직 정상 복구.
