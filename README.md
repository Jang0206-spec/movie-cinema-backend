# 📌 Movie Cinema (온라인 영화 예매 및 리뷰 시스템) - V1.0.0

> **상태: 🚀 Phase 1 (JSP/Servlet 레거시 코드 백업 완료 / Spring Boot 리팩토링 준비 중)**
> 
> 본 프로젝트는 학부 과정에서 개발한 JSP/Servlet 기반 원본 서비스입니다. 현재 이 저장소는 과거의 레거시 코드를 백업한 상태이며, 향후 현대적인 백엔드 아키텍처(Spring Boot + 분산 인프라)로 리팩토링하며 기술적 부채를 해결해 나가는 과정을 기록할 예정입니다.

---

## ⚙️ 오리지널 아키텍처 및 개발 환경 (V1.0.0)

* **Language & Framework:** Java (JDK 17), JSP/Servlet (MVC 패턴 표준 준수)
* **Database:** MySQL 8.0
* **Web Server:** Apache Tomcat 11.0
* **IDE:** Eclipse

---

## 💾 데이터베이스 설계 (ERD 요약)

총 4개의 핵심 엔티티를 구성하여 각 데이터 간의 트랜잭션을 구현했습니다.

* **`member` (회원):** 사용자 ID, 암호화된 비밀번호, 연락처, 권한(`role`을 통한 관리자/일반 사용자 구분).
* **`movie` (영화):** 영화 제목, 감독, 가격, 러닝타임, 포스터 이미지 경로.
* **`movie_reservation` (예매):** 회원이 예매한 영화, 상영 날짜/시간, 인원 수, 좌석 정보(문자열 형태), 총 결제 금액.
* **`review` (리뷰):** 회원이 영화에 남긴 평점, 한줄평 내용.

## 🚀 주요 구현 기능

### 1. 세션 기반 인증 및 권한 제어
* **보안:** 사용자 비밀번호는 평문 저장을 방지하기 위해 `SHA-256` 해싱 알고리즘을 적용하여 단방향 암호화 수행.
* **권한 분리:** `HttpSession` 객체를 활용하여 로그인 상태를 유지하고, 관리자(`admin`)와 일반 사용자의 접근 가능한 페이지 및 기능을 분리.

### 2. 영화 예매 및 좌석 데이터 처리
* 별도의 좌석 테이블을 두지 않고, 여러 좌석을 "A1,B2" 형태의 단일 문자열로 결합하여 DB에 저장.
* 조회 시 Java의 `split()` 함수를 통해 파싱하여 화면에 렌더링.

### 3. 대용량 데이터 조회를 위한 페이징
* MySQL의 `LIMIT ?, ?` 구문을 활용하여 한 페이지당 4개의 영화만 가져오도록 쿼리 최적화.

## 🛠️ 기술적 챌린지 및 트러블슈팅 (V1 기준)

**1. 동적 경로 제어로 404 에러 방어**
* **이슈:** 깊이가 다른 JSP 파일에서 공통 헤더 공유 시 상대 경로 링크 깨짐 발생.
* **해결:** `request.getContextPath()`를 사용하여 프로젝트 최상위 루트를 동적으로 가져오도록 수정.

**2. 데이터 공백으로 인한 권한 처리 오류**
* **이슈:** DB 상에서 관리자 권한(`admin`)을 부여했으나 일반 유저로 인식되는 논리 오류.
* **해결:** 콘솔 디버깅을 통해 DB 데이터에 보이지 않는 공백이 있음을 확인하고, `.trim()` 메서드를 적용하여 데이터 무결성 확보.
